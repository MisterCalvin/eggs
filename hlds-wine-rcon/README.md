## hlds-wine-rcon

An egg running HLDS under Wine, typically used for Goldsrc mods which only provide Windows binaries. Once the server has started, a logaddress is added to loopback, so you can see all server messages live and interact with console via the Pterodactyl panel. Import the egg into your panel via `Nests -> Import Egg`
